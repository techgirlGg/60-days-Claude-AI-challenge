# Day 4/60 – AI Career Roadmap Generator

## 📌 Challenge Overview

Today's challenge focused on building an **AI Career Roadmap Generator** using structured prompting.

The goal was to create a system that can understand a user's current situation, identify skill gaps, and generate a personalized roadmap toward their desired career goal.

---

## 🎯 Objective

Design an AI assistant that:

* Collects user information through MCQs
* Identifies the user's current stage
* Detects missing skills
* Creates a high-ROI learning path
* Generates a one-page career roadmap

---

## 🧠 Prompting Technique Used

### Structured Information Gathering

Instead of generating advice immediately, the AI first asks targeted multiple-choice questions to understand:

1. Current Situation
2. Existing Skills
3. Career Goal
4. Timeline

This ensures that recommendations are personalized rather than generic.

---

## 🚀 Output Structure

The AI generates:

### Current Position

* Present skill level
* Current career stage

### Skill Gaps

* Missing technical skills
* Missing practical experience

### Roadmap

#### Phase 1

Foundation Building

#### Phase 2

Skill Development

#### Phase 3

Industry Readiness

### Recommended Projects

* Portfolio Projects
* Real-world Applications
* Showcase Projects

### Success Formula

A concise motivational statement.

---

## 💡 Key Learning

The quality of AI output improves significantly when information is collected in a structured format before generating recommendations.

Instead of giving generic career advice, the AI becomes a personalized career mentor.

---

## 🔥 Takeaway

**Ask better questions first. Better inputs create better outputs.**
